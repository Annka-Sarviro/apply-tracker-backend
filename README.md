🚀 Apply Tracker Backend

Це бекенд-частина проєкту **Apply Tracker**, реалізована на базі **NestJS**. Вона відповідає за обробку API-запитів, зберігання даних, авторизацію користувачів і логіку відстеження вакансій.

---

## 🧩 Технології

- 🧠 **NestJS** — фреймворк для побудови масштабованих Node.js-серверів
- 🐘 **PostgreSQL** — основна база даних
- 🔐 **JWT** — для авторизації
- ⚙️ **TypeORM** — ORM для роботи з БД
- 🔄 **Swagger** — автогенерація документації API

---

## 🚀 Швидкий старт

### 🔧 Встановлення

```bash
git clone https://github.com/Annka-Sarviro/apply-tracker-backend.git
cd job-tracker-backend

## Запуск


```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```
